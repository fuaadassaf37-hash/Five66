# الديوان العسكري — النسخة المتصلة بالسيرفر

> ⚠️ **تحديث أمني مهم**: النسخة السابقة كانت لا تطبّق أي حماية فعلية على السيرفر رغم وجود `APP_USER`/`APP_PASS` في `.env` —
> أي شخص يعرف رابط السيرفر كان يقدر يقرأ أو يكتب كامل قاعدة البيانات (`/api/state`, `/api/backup`) بدون تسجيل دخول.
> تم الآن تفعيل حماية **Basic Auth حقيقية على كامل السيرفر** (الواجهة + كل الـ API)، والسيرفر **يرفض العمل من الأساس**
> إذا لم يجد `APP_USER` و`APP_PASS` في `.env`. غيّر القيم الافتراضية في `.env` فوراً قبل النشر، ولا تستخدم كلمات مرور قصيرة
> مثل الأرقام فقط — هذه بيانات عسكرية حساسة (شهداء، جرحى، خصومات).

تم تحويل التطبيق ليصبح **مرتبطاً بسيرفر**: كل تعديل (إضافة شخص، خصم، تفقد، شهيد، جريح...)
يُحفظ تلقائياً في قاعدة بيانات على السيرفر، ويصل لجميع من يفتح الموقع من أي متصفح على الشبكة أو الإنترنت.

---

## 1. محتويات الحزمة

```
server/
├── server.js          ← السيرفر (Express + Socket.io)
├── package.json
├── .env                ← اسم المستخدم وكلمة المرور والمنفذ
├── data/
│   └── state.json       ← هنا تُخزَّن كل التعديلات (يُنشأ تلقائياً)
└── public/
    └── index.html        ← واجهة التطبيق (نفس التطبيق بعد التعديل)
```

---

## 2. التشغيل على الـ VPS

### المتطلبات
- يفضّل Ubuntu 22.04/24.04
- تثبيت Node.js (الإصدار 18 أو أحدث):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt-get install -y nodejs
```

### رفع الملفات وتشغيل السيرفر
```bash
# 1. نقل مجلد server بالكامل إلى السيرفر (عبر scp أو git أو FTP)
scp -r server user@SERVER_IP:/home/user/diwan

# 2. الدخول للسيرفر
ssh user@SERVER_IP
cd /home/user/diwan

# 3. تثبيت الحزم
npm install

# 4. (اختياري) تعديل اسم المستخدم/كلمة المرور والمنفذ
nano .env

# 5. تشغيل السيرفر
npm start
```

سيظهر لك:
```
✅ سيرفر الديوان العسكري يعمل على المنفذ 3000
```

افتح من أي متصفح: `http://SERVER_IP:3000`
وسيُطلب منك اسم المستخدم وكلمة المرور (المحددين في ملف `.env`).

## 3. التشغيل بشكل دائم (لا يتوقف عند إغلاق الجلسة)

استخدم `pm2`:
```bash
sudo npm install -g pm2
pm2 start server.js --name diwan
pm2 save
pm2 startup     # لتشغيله تلقائياً عند إعادة تشغيل السيرفر
```

## 4. (اختياري) ربط دومين + HTTPS

إذا عندك دومين، ركّب Nginx كـ reverse proxy، ثم استخدم Certbot لشهادة SSL مجانية:

```bash
sudo apt install nginx certbot python3-certbot-nginx -y
```

أنشئ ملف `/etc/nginx/sites-available/diwan`:
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```
```bash
sudo ln -s /etc/nginx/sites-available/diwan /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d your-domain.com
```

## 5. كيف تعمل المزامنة؟

- عند فتح الصفحة: تجلب الواجهة آخر نسخة محفوظة من السيرفر (`/api/state`).
- عند أي تعديل (حفظ شخص، خصم، تفقد...): تُرسل البيانات فوراً للسيرفر وتُحفظ في `data/state.json`.
- إذا قام **مستخدم آخر** بالتعديل أثناء فتحك للصفحة: يظهر شريط أسفل الصفحة
  "⚠ تم تحديث البيانات من مستخدم آخر — اضغط هنا لتحميل آخر التحديثات"
  لتجنب فقدان أي تعديل تكتبه أنت حالياً، التحديث يدوي (بالضغط على الشريط) وليس تلقائياً بالكامل.
- إذا انقطع الاتصال بالسيرفر: تستمر البيانات بالحفظ محلياً (مثل السابق) ويظهر تنبيه صغير،
  وعند رجوع الاتصال يمكن إعادة الحفظ من جديد.

---

## 6. النسخ الاحتياطي

- ملف `server/data/state.json` يحتوي كل التعديلات — يُنصح بنسخه احتياطياً بشكل دوري:
```bash
cp server/data/state.json backup-$(date +%Y%m%d).json
```
- أو عبر المتصفح: `http://SERVER_IP:3000/api/backup` (سيطلب اسم المستخدم وكلمة المرور).

---

## 7. ملاحظات هامة

- البيانات الأساسية (قائمة الأفراد الأصلية) **محفوظة داخل ملف `index.html` نفسه** كما كانت سابقاً —
  فقط **التعديلات والإضافات** (شهداء، جرحى، خصومات، تفقد، أفراد جدد/معدّلين) تُخزَّن وتُزامن عبر السيرفر.
- شاشة تسجيل الدخول الأصلية (المشفّرة) أُزيلت من هذه النسخة، واستُبدلت بحماية على مستوى السيرفر
  (اسم المستخدم وكلمة المرور في `.env`) — وهذا أنسب وأكثر أماناً للوصول عبر الإنترنت.
- يمكن تغيير اسم المستخدم/كلمة المرور بتعديل ملف `.env` وإعادة تشغيل السيرفر.
